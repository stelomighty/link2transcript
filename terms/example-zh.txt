# 格式：错=>对，一行一条，# 开头是注释。
# 只改字幕正文，序号行和时间轴行不动。
# 纯 ASCII 的模式按整词匹配（AI 不会命中 TRAIL），中文按子串替换。
#
# ── 收录标准（只有一条）──────────────────────────────
# 左边那个词，在你的场景里几乎不可能是对的。
#
# 可以收：射程=>设成      （「射程」在技术口播里基本不会出现）
# 不要收：长轮=>长轮询    （左边是别的词的前缀，会把正确的词也切坏）
# 不要收：三期=>三奇      （左边本身是常用词，误伤成本远高于漏改）
#
# 左边是常用词的情况交给 --hint 在转录阶段解决，别用词表硬擦。
